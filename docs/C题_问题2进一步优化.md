# 问题2进一步优化测试

## 1. 跨日储能连续优化

原问题2按每天 `SOC(0)=SOC(24)=6000 kWh` 独立求解。将334天串联为一个线性规划，仅约束全年起点与终点SOC均为6000 kWh，允许储能跨日传递后，得到：

- 334天购电量：20,189,815.797851 kWh；
- 334天购电费：12,230,383.646208 元；
- 限光量：990,168.090312 kWh。

相对逐日闭合基线（20,218,838.180253 kWh、12,245,046.915278元），购电量减少约29,022.38 kWh，费用减少约14,663.27元。该改进来自跨日利用储能，并未改变附件数据；若严格将“当天策略”解释为每日独立，则保留逐日闭合作为主口径，连续模型作为优化上界/敏感性结果。

## 2. 有紧急购电时的保守预报优化

在“0:00预报—实际执行”模型中，以 `α·PV预报`作为计划阶段的保守光伏值。对 α=1.00、0.95、0.90、0.85、0.80 测试后，α=0.85总费用最低：

- 问题3：16,340,278.317906 元，紧急购电397,261.777886 kWh；
- 波动电价问题4-3：16,973,795.163453 元，紧急购电401,431.559463 kWh。

因此在允许外购电且重视紧急购电惩罚时，建议采用 α=0.85；α=0.80虽进一步减少紧急购电，但正常计划购电增加过多，总费用反而上升。
