## 1. 题目一句话概括

在**已知小区负载、光伏出力（或预报）与电价**的条件下，逐 10 分钟决定**向外部电网的计划购电量**与**储能充放电量**，在"微网供电不得低于负载"和储能物理约束下**最小化全天购电费用**；四个问题依次递进为：确定性日计划 → 引入紧急购电罚项 → 引入多时刻预报的计划—调整两阶段 → 电价本身波动。

## 4. 四问统一模型框架

统一为同一族线性规划；差异只在**信息结构、约束项与目标项**。

### 4.1 统一符号

| 符号 | 含义 | 域 |
|---|---|---|
| `t` | 10 分钟时段索引 | 1..144（覆盖 `[(t−1)/6, t/6)` 小时） |
| `d` | 日期索引 | 2025-02-01 .. 2025-12-31（334 天） |
| `p_t` | 计划购电量 | ≥ 0，kWh |
| `x_t` / `y_t` | 充电量 / 放电量 | [0, 833.3333]，kWh |
| `S_t` | 时段末储电量 | [1200, 10800]，kWh |
| `z_t` | 紧急购电量 | ≥ 0，kWh |
| `p^plan_t` / `p^adj_t` | 0:00 计划 / 调整后最终执行购电量 | ≥ 0，kWh |
| `g_t` | 弃光/限光量（可选松弛） | [0, `pv_t·Δt`]，kWh |
| `c_t` | 电价 | 元/kWh（问题1/2/3 用附件1；问题4 用附件4） |

记 `net_t = (load_t − pv_t)·Δt`（kWh，可负）。

### 4.2 核心约束（四问共用）

```
功率平衡（题面口径：微网供电不得低于负载 → 不等式）
    p_t + y_t + (pv_t·Δt − g_t)  ≥  load_t·Δt + x_t
等价
    p_t  ≥  net_t + x_t − y_t + g_t
SOC 递推
    S_t = S_{t−1} + 0.9·x_t − y_t/0.9
边界与限值
    1200 ≤ S_t ≤ 10800,  S_0 = S_144 = 6000
    0 ≤ x_t, y_t ≤ 833.3333,  p_t ≥ 0,  0 ≤ g_t ≤ pv_t·Δt
```

**量纲红线**：附件1/2/4 的负载与光伏是**功率（kW）**，所有参与能量平衡的量必须先乘 `Δt = 1/6` 转为 **kWh**。单时段上限是 **833.3333 kWh**，不是 5000 kWh。

### 4.3 四问差异

| | 电价 | 负载/光伏 | 日终 SOC | 紧急购电 | 调整罚项 | 信息结构 |
|---|---|---|---|---|---|---|
| 问题1 | 附件1（典型日） | 附件1 | `S_144 = 6000` | 不触发 | 无 | 完全信息 |
| 问题2 | 附件1 | 附件2 实际（逐日） | `S_144 = 6000` | `5·c_t·z_t` | 无 | 完全信息（逐日独立） |
| 问题3 | 附件1 | 附件2 实际 + 附件3 预报 | `S_144 = 6000` | `5·c_t·z_t` | 下调 `0.5·c_t`、上调 `1.5·c_t` | 两阶段/滚动，非预期 |
| 问题4 | 附件4（波动） | 附件2 实际 + 附件3 预报 | `S_144 = 6000` | `5·c_t·z_t` | 同问题3 | 电价不确定（D1/D2 两口径） |

### 4.4 问题3 费用口径（已裁定）

```
总费用 = Σ_t c_t·p^plan_t                                        （计划购电费）
       + Σ_t 5·c_t·z_t                                           （紧急购电费）
       + Σ_t 1.5·c_t·max(p^adj_t − p^plan_t, 0)                  （超购部分）
       + Σ_t 0.5·c_t·max(p^plan_t − p^adj_t, 0)                  （违约部分）
```
`调整购电量` 工作表存**最终执行的购电量** `p^adj_t`（不是差值）。
非预期性：`p^plan` 只能依赖 0:00 已发布信息；`p^adj`（6:00 之后）可依赖该时刻已发布的预报。
**调整的承诺范围**：覆盖**当日至 24:00**，且要求日终储电量归位（`S_144 = 6000`），与问题1/2 口径一致。

## 5. 问题1 参考解（队长独立 LP，权威对账基准）

模型：577 变量（`S_0..S_144` 共 145 个 + `x, y, g` 各 144 个；`p` 由平衡式回代），144 行 SOC 递推等式 + 144 行非负性不等式，`scipy.linprog(method="highs")`。

| 量 | 值 |
|---|---|
| 全天购电量 | **59 482.70 kWh** |
| 全天购电费 | **35 126.95 元** |
| 限光/弃光量 | **0.0000 kWh** |
| 充电总量 / 放电总量 | 20 740.67 / 16 799.94 kWh |
| `Σy/Σx` | **0.8100**（= `η²`，无额外损耗时的理论关系 ✓） |
| SOC 范围 | [1200, 10800]；`S_0 = S_144 = 6000` |
| 公平基线（不装储能 + 允许弃光） | 48 052.05 元 |
| **储能净收益** | **12 925.10 元（26.90%）** |

**残差自检（本次逐项独立测量，非空断言）**：SOC 递推 `8.7e-13`；`A_eq·z − b_eq` `4.5e-13`；功率平衡 `0.0`；目标复算 `0.0`；SOC 越界 `0.0`。

**物理合理性**：负载总量 111 024.81 kWh，光伏总量 55 482.84 kWh ⇒ 净需求 55 541.97 kWh；购电量 59 482.70 kWh 高出 3 940.73 kWh（= 储能往返损耗 `Σx − Σy = 3 940.73`），逻辑闭合。

> **本版修正记录**：上一版报告 58 909.39 kWh / 34 886.19 元 / `Σy = 17 373.25`，**已作废**。该版 SOC 递推存在两处缺陷：递推循环只生成 143 行、**漏掉一个时段的递推**；且 `S_0 = S_INIT` 被写成硬等式，使**时段 0 的充放电不进入任何守恒关系**（实测 `y_0 = 573.31 kWh` 凭空放电）。其自报的"残差 4.5e-13"是对 `A_eq` 求残差，而该矩阵恰好缺那一行，属**空断言**。
> 感谢编程手与建模手独立发现该异常：前者用 `Σy/Σx = 0.9463 ≠ 0.81`、后者用 `residual_soc = 1590.34` 分别命中。修正后 `Σy/Σx = 0.8100`，且与编程手自建 720 变量 LP（Σp = 59 482.70、Σc·p = 35 126.95）**逐位吻合**。

> ⚠️ **建模手 t1 报告的 359 079.50 kWh / 269 683.19 元不成立**：该购电量超过"全天按最大负荷满额外购"的上限（解析上界 `Σp ≤ 133 824.81 kWh`，超界 2.68 倍），且费用高于不装储能的公平基线。问题2/3/4 的参考解需据此重算。定位提示见 `docs/C题_三方一致性核对.md` §A9。

### 6.2 两个必须遵守的陷阱

**陷阱 1（列口径）**：宽表时间段列共 **144** 个，**第 `i` 列的字面标签**对应规范区间 `label(i+1)`；第 144 列表头为 `0:00-0:10+1`，**字面语义是次日首个区间**。**当日 `0:00-0:10` 在宽表中没有独立列**，只体现在 `全天购电量` 汇总。

> ⚠️ **读盘口径与写盘口径必须分开（队长裁定 A18）**——这两句看似矛盾，实为两个作用域：
>
> | 场景 | 第 `i` 个数据位的含义 | 用哪个标签函数 |
> |---|---|---|
> | **读模板**（解释模板自己的列） | 区间 `i+1` | `io.template_column_to_interval(i)` = `i+1` |
> | **写结果**（本队方案 A 口径） | **时段 `t = i`** | `io.write_plan_columns()` → `interval_label(i)` |
>
> 即：**数据位 `i` 装的是 `t = i` 的购电量**（A4 裁定），而模板把该位置**字面标成** `label(i+1)`。
> 因此末列按方案 A 填 `t = 144`（当日 `23:50-0:00+1`）的值，而它的表头字符串仍是 `0:00-0:10+1`
> —— **表头字符串与数据语义在该列不一致，属模板固有瑕疵**，须在论文表注中声明（见 A15 与 §6.3）。
> 混用两个函数会让整表错位一格。

⇒ **取数/写盘必须按列名字符串匹配，禁止 `列序号 = t + 1` 之类的算术推断。**

**陷阱 2（`result1` 行口径）**：模板 144 行**缺当日 `t=1`**、末行换成**次日首时段**（第 `r` 行 = 区间 `r+1`）。
⇒ **裁定采用方案 A**：写 144 行，行标签用附件1 口径 `0:00-0:10 … 23:50-0:00+1`，第 `r` 行写 `t = r`。
⇒ 必须在文档与代码注释中显式声明该差异。

### 3.4 问题1 可外推性的正确论据（经复核修正）

> 本条修正了早期"均值化把负载日内峰谷平滑至约 73%"的表述。复核结论：**日内平滑幅度很小，不足以支撑"不可外推"**；真正的障碍是**日间波动与负荷—电价的正相关结构**。

**(a) 日内平滑幅度（同名同量纲口径，唯一可比）**

| 序列 | `std(附件1 曲线)` | `median(全年逐日日内 σ)` | 平滑系数 | 峰谷差（附件1 / 中位日） |
|---|---|---|---|---|
| 负载 | 977.47 | 1200.91 | **0.8139** | 2649.6 / 3640.0 kW |
| 光伏 | 2854.40 | 2951.12 | **0.9672** | 7612.3 / 8161.1 kW |
| 电价 | 0.3133 | 0.3180 | **0.9853** | 1.02 / 1.06 元/kWh |

口径声明（**三种分母语义不同，不可混用**；此前的 0.952/0.970 混用了含日间波动的 `std(逐时刻 σ 向量)` 分母，已废弃）：

| 记号 | 定义 | 语义 | 负载值 |
|---|---|---|---|
| D1 | `std(附件1 曲线)` | 均值曲线自身的日内波动 | 977.47 |
| D2 | `median(全年逐日日内 σ)` | "典型一天"的日内波动 | 1200.91 |
| D3 | `std(逐时刻 σ 向量)` | 各时刻跨日波动的离散度 | 339.89 |
| D4 | `mean(逐时刻 σ 向量)` | 各时刻跨日波动的平均水平 | 960.22 |

**D1/D2 = 0.8139 是唯一同量纲可比的口径**（两者都是"日内波动"）。注意 D1/D4 = 1.0180（负载），与 D1/D2 差异巨大——**分母选错会得到完全相反的结论**。

**(b) 真正的论据：日间波动与正相关结构**

| 量 | 实测值 |
|---|---|
| 日负荷总量 CV | **19.65%** |
| 日光伏总量 CV | **20.81%** |
| 日电价均值 CV | **13.52%** |
| **日负荷总量 vs 日电价均值 相关系数** | **r = +0.8977** |
| 日光伏总量 vs 日电价均值 相关系数 | r = −0.3431 |
| 日负荷总量 vs 日光伏总量 相关系数 | r = +0.0689 |

**结论（论文应用此表述）**：问题1 用**固定的电价向量搭配固定的负载曲线**，丢掉了「**高负荷日恰是高价日**」这一强正相关结构（`r = +0.898`）；同时日负荷总量本身有 19.65% 的日间波动。因此典型日的最优购电费**既不等于全年平均费用、也不代表任何真实单日**，不可外推。
反过来，日光伏总量与日电价均值呈负相关（`r = −0.343`），因为光伏大发会压低电价——这一结构在问题1 中同样被抹掉。
