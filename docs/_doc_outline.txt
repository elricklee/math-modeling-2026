■ 1. 问题重述与统一化

▸▸ 1.1 物理系统

非孤岛式微网 = 小区负载 + 光伏 + 储能 + 外部电网（外网）。

  • 光伏优先本地消纳，余量给储能充电；
  • 外网电价低时多买电（供负荷或给储能充电），电价高时靠储能放电替代外购电；
  • 目标是在满足小区负载的前提下最小化微网购电费用。

▸▸ 1.2 决策链


│ 0:00 观测(电价, 净负荷) ─► 制定计划购电策略 p^plan ─┐
│                                                   ├─► 实际执行时按偏差结算
│ 其他预报时刻(6/12/18) ─► 制定调整策略 p^adj ──────┘
│ 若供能不足 ─► 紧急购电 z（电价 = 交易时刻电价 × 5）

结论：附件1 = 附件2（负载、光伏）与附件4（电价）在 2025 全年的逐时刻算术平均曲线（写成 10 分钟粒度）。

与队长裁定 1 的合并结论（已双向独立验证，二者互补而非冲突）：队长用逐日反查证明 附件1 与 2025 年任何一天都不精确相等（精确匹配天数 = 0）——这与"附件1 = 365 天均值"完全自洽：均值曲线按定义就不等于任何单日曲线。定量判据如下（建模手复核）：

+------+------------------+--------------+--------+-------------------+
| 列    | 与 365 天逐列均值的平均偏差 | 各列日间标准差均值    | 比值     | 与各日的 MAE（最小 / 中位） |
+------+------------------+--------------+--------+-------------------+
| 电价   | 0.000026 元/kWh   | 0.1240 元/kWh | 2.1e-4 | 0.0330 / 0.0871   |

| 光伏   | 0.000905 kW      | 533.1 kW     | 1.7e-6 | 103.35 / 437.79   |
+------+------------------+--------------+--------+-------------------+

判读：若附件1 取自某个单日，其偏离均值的期望 MAE 应为"列标准差 × √(2/π)"≈ 767 kW（负载）／0.099 元（电价）；实测仅 2.8e-5 kW／2.6e-5 元，比日间波动小 4–8 个数量级。附件1 是均值曲线，不是任何单日。

推论（编程手/论文手必须遵守）：
  1. 问题1 的"某一天"= 2025 年典型日（365 天逐时段均值曲线），其负载/光伏与附件2 中任何一天都不相同（最近似日为负载第 97 行 2025-02-28、光伏第 79 行 2025-02-10，MAE 仍达 286.9 kW / 103.4 kW），不要去附件2 里找对应日期，更不要在论文中写成"附件1 对应 2025 年 X 月 X 日"（无据推断）；
  2. 正确表述（已被队长裁定 1 与编程手独立核实，三方一致）："附件1 为 2025 年典型日的日均曲线（逐时段取全年 365 天平均），问题1 在该典型日上优化；该典型日不参与 2025 年日历索引"。题目"若每天的电价和小区负载相同"正是对这一典型日的设定，问题1 的题面因此完全自洽——不要写成"附件1 是独立构造的单日代表曲线"（编程手原文档的表述已按此修正）；
  3. 舍入一致性：四舍五入到 4 位小数后，附件1 与逐列均值在 电价 142/144、负载 141/144、光伏 133/144 个时段精确相同（建模手复核：142/144 与 141/144 完全复现），可直接作为数据自检用例；
  4. 附件2/4 虽含 2025-01-01（它为附件1 的均值提供了一天样本），但不用于问题1；
  5. 问题1 的最优费用是"典型日最优"，不能外推为 334 天的平均最优费用，理由与量化依据见 4.7（论文必须显式声明，否则会被追问问题1 与问题2 的费用差异）；
  6. 附件1 电价 min/max/mean = 0.3713 / 1.3952 / 0.7662，均值 0.7662 与附件4 全年均值完全一致 → 可作交叉验证；
  7. 附件4 电价 min/max = 0.0076 / 1.7936（均值 0.7662），存在 9 个 < 0.05 元/kWh 的极端低价样本（2025-04-26 当日 max/min = 157），极端值会主导问题4 的解，需按 9.5 节口径处理。

▸▸ 1.4 四问的统一表达

记 t ∈ 𝒯 = {1, …, 144} 为 10 分钟时段，Δt = 1/6 h。统一模型：


│ (P)   min  Σ_t  [ c_t · p_t  +  5·c_t · z_t ]  +  Δ(计划偏差项)
│       s.t.
│       p_t + y_t − x_t − g_t − z_t = net_t·Δt = (load_t − pv_t)·Δt   ∀t （能量平衡，kWh）
│       S_t = S_{t-1} + η·x_t − y_t/η                              ∀t （SOC 递推，kWh）
│       S_lo ≤ S_t ≤ S_hi,   S_0 = S_144 = S_init                  （容量与首末）
│       0 ≤ x_t ≤ x̄,  0 ≤ y_t ≤ ȳ,  0 ≤ g_t ≤ pv_t·Δt               （充放电与限光）
│       0 ≤ p_t,  0 ≤ z_t                                          （购电与紧急购电非负）

其中 g_t 为光伏限光量（松弛变量，见 4.2.1/9.8），问题1/2/3/4 全部需要。

+-----+----------+-----------------+--------------------+---------------+-----------------+--------------+

▸▸ 4.2 模型 (P1)


│ 目标：   min  Σ_{t=1}^{144}  c_t · p_t                              （全天购电费最小）
│ 
│ s.t.    p_t + y_t − x_t − g_t = net_t·Δt            t = 1..144        （能量平衡，含限光松弛）
│         S_t = S_{t−1} + η·x_t − y_t/η              t = 1..144        （SOC 递推）
│         S_0 = 6000,  S_144 = S_0                                     （首末相等）
│         1200 ≤ S_t ≤ 10800                         t = 1..144

│ 
│ 输出：  P_day = Σ p_t (kWh)，C_day = Σ c_t p_t (元)，S_0、S_144、X_b、Y_b

▸ g_t（光伏限光量）不是可选装饰，而是本题必需的松弛变量。 见 4.2.1 与 9.8。

▸▸▸ 4.2.1 限光松弛 g_t 的必要性（本节已按队长 A8 裁定勘误）

初版结论的错误：初版写"附件1 中午净负荷低至 −2117.5 kWh，是单时段吸收上限 833.3333 kWh 的 2.54 倍，故 22/144 时段违反"。这是把功率（kW）当成了电量（kWh）。正确换算：


│ 净负荷最小功率 = −2117.5 kW  =  −2117.5 × Δt  =  −352.9209 kWh/时段

仅为单时段吸收上限 833.3333 kWh 的 42.4%。实测 0/144 时段越限，附件1 的 30 个负余量时段（合计 6,247.96 kWh）全部可被储能吸收。

修正后的结论（方向正确，但论据与作用范围不同）：

  1. g_t 仍然必须出现在模型中，因为它是一个可行域松弛：题面"微网提供的电能不可低于小区负载"是不等式（p_t ≥ 0），配合"不允许上网"，光伏余量在原理上可能无法被吸收；若把平衡写成等式且不设 g，模型会出现"强制储能吸收全部余量"的刚性问题（队长首版 LP 正是因此在附件1 上不可行）。
  2. 但在附件1 上 g 的最优取值为 0 —— 全时段余量都能入储能，不需要弃光。论文中不要写"必须限光否则不可行"，该说法已被实测证伪。
  3. 等价写法：把功率平衡写成不等式 p_t + y_t − x_t ≥ net_t·Δt（即 p_t ≥ 0），即可自然地允许余量不被吸收，无需显式引入 g_t。本队主口径仍保留显式 g_t（便于报告 Σg_t 并统一问题2/3/4 的写法），两者最优值相同。
  4. 在问题2 的全年数据上 g 才真正起作用：365 天中有 34 天存在单时段余量超过 833.3333 kWh 的时段（无法靠储能单独吸收），全年限光 990,168.09 kWh，占全年光伏余量（3,120,221.00 kWh）的 31.7%。所以 g_t 不是装饰，而是问题2/3/4 的必要组件。

▸ 单位铁律再强调：本节的错误根源与 §0 警告的是同一个坑——附件的负荷/光伏/电价都是功率量纲（kW），而模型的 p/x/y/S 是电能量纲（kWh），中间必须乘 Δt = 1/6。凡见到"净负荷 = −2117.5"这样的数字，先问一句：它是 kW 还是 kWh？

▸▸ 4.3 等价化简（强烈建议编程手使用）

将平衡式代入目标，常数项 Σ c_t·net_t·Δt 可提出，得到只含 x、y、g 的等价 LP：


│ min  Σ c_t (x_t − y_t)                                   （g 无成本；constant = Σ c_t·net_t·Δt）
│ s.t. S_t = 6000 + Σ_{τ≤t} (0.9 x_τ − y_τ/0.9) ∈ [1200, 10800],  0 ≤ x_t, y_t ≤ 833.3333
│      net_t·Δt + x_t − y_t − g_t ≥ 0   ⟺   y_t + g_t ≤ net_t·Δt + x_t     （购电非负）
│      g_t ≥ 0（上界 pv_t·Δt，最优解中不紧）
│      S_144 = 6000

（Σ c_t(x_t − y_t) 的常数项为 Σ c_t·net_t·Δt；g_t 本身不进目标，只在约束中被"用满"以满足非负性）

最终 p_t = net_t·Δt + x_t − y_t − g_t 由平衡式回代得到，无需单独作为变量（仍建议保留 p 变量以便直接对应表1）。注意 net_t·Δt 里的 Δt 不能省——这是全部电量的量纲来源。

▸▸ 4.4 最优性来源与结构讨论（论文手重点段落）

命题 1（凸性与存在性） (P1) 是标准形式的线性规划，可行域非空（取 x = y = 0, g_t = max(−net_t·Δt, 0), p_t = max(net_t·Δt, 0) 可行），目标有下界（c_t > 0, p_t ≥ 0），故最优解存在且最优值唯一（最优解可能不唯一）。

命题 2（"不可低于负载"的经济学含义） 约束 p_t ≥ 0 意味着储能不得使外网购电出现缺口（下列 net 均指 net_t·Δt，kWh）：
  • 当 net_t > 0（缺电时段）：最多可用 y_t ≤ net_t·Δt + x_t + g_t 的放电替代外购；
  • 当 net_t < 0（光伏余量时段）：p_t = net_t·Δt + x_t − y_t − g_t ≥ 0 要求 y_t + g_t ≤ net_t·Δt + x_t < x_t，即余量时段只能充电或最少放电，或弃光（这正是 g_t 的作用）。

命题 3（套利条件） 只在时段 τ 充电 x、在时段 t 放电 y（两段都不触碰 p 的非负边界之外的其它约束）时，电费变化为

│ Δcost = c_τ·x − c_t·y,   电量守恒要求 y = η²·x = 0.81x
│ ⟹ 划算 ⟺ c_t / c_τ > 1/η² = 1.2346

即电价峰谷比必须超过 1.2346（=1/0.81）才值得做跨时段套利。附件1 电价 max/min = 1.3952/0.3713 = 3.76 > 1.2346，故存在套利空间；但受"不得低于负载"约束，可套利的电量受限于 Σ(净负荷·Δt) 的缺口规模。

▸▸ 4.7 问题1 结果的可外推性（论文必须声明）

问题1 的解是"典型日最优"，不等价于 334 天的平均最优。 论文中若不声明，会被追问"为什么问题1 与问题2 的费用量级差异大"。三个必须交代的机制：

  1. 问题1 与问题2 的电价口径完全相同（都是附件1 的 144 个日均电价）——差异全部来自负荷与光伏的日间波动。参见 5.1。
  2. 附件1 的日内波动被平滑，但"平滑"三个口径不可混用。本段已按队长 A17 裁定统一（ddof = 0）：

+----+------------------+---------+---------+--------+-------------+
| 记号 | 定义               | 负载      | 光伏      | 电价     | 语义          |
+----+------------------+---------+---------+--------+-------------+
| D1 | std(附件1 曲线)      | 977.47  | 2854.40 | 0.3115 | 均值曲线自身的日内波动 |
| D2 | median(全年逐日日内 σ) | 1200.91 | 2951.12 | 0.3161 | "中位日"的日内波动  |
| D3 | std(逐时刻 σ 向量)    | 334.58  | 428.34  | 0.0328 | 跨日波动的离散度    |
| D4 | mean(逐时刻 σ 向量)   | 1027.12 | 2877.42 | 0.3194 | 跨日波动平均水平    |
+----+------------------+---------+---------+--------+-------------+

  • 唯一同量纲可比的是 D1/D2：负载 0.8139、光伏 0.9672、电价 0.9853（分子分母都是"日内波动"）。
  • D1/D4 属混口径，不可使用：建模手第二轮提出的 0.952（负载）即此，已按裁定撤回；编程手的"σ 仅为实况的 69%"是把日内 σ 除以全年逐时段 σ（1411.75，含日间波动），同样混口径，亦不采用。
  • D1/D2 = 0.8139 的正确读法：它刻画"均值曲线相对中位日的日内波动比"。不要反推成"平滑掉 18.6% 的波动 / 73% 的方差"。更稳健的是给出相对离散度（CV 比，不受量纲影响）：

│      相对离散度比 = (D1 / mean₁) ÷ (D2 / mean_day)

负载 0.8773、光伏 0.9821、电价 0.9869；即均值曲线相对中位日仍保留 约 88% 的相对日内离散度，"形状"并未被显著抹平。（mean₁ ≈ mean_day ≈ 4626.04 kW。）
  • 方差分解（建模手补充的恒等式）：E_d[Var_t(X_{d,t})] = Var_t(均值曲线) + E_t[Var_d(X_{d,t})] ≈ D1² + D3²。
负载校验：977.47² + 334.58² = 955 449 + 111 944 = 1 067 393，vs 实测 E[日内方差] = 1 120 231（差 4.7%）。该式说明 D1² 与 D2² 的差额主要来自 D2 把"日间水平差异"计入了单日曲线，而不是"平滑造成的损失"。
  3. 真正的外推障碍是日间波动与联合分布，而不是日内平滑：

+----------+-------------------------------------+
| 量        | 日均值变异系数                             |
+----------+-------------------------------------+
| 小区负载（日均） | 19.7%（mean 4626.0 kW，σ 910.1 kW）    |
| 电价（日均）   | 13.5%（mean 0.7662 元/kWh，σ 0.1037）   |
| 光伏（日总量）  | 20.8%（mean 55 483 kWh，σ 11 563 kWh） |
+----------+-------------------------------------+

关键相关：日负荷总量 vs 日电价均值 r = +0.898（高负荷日恰是高价日）；日光伏总量 vs 日电价均值 r = −0.343（晴天光伏多、电价略低）。问题1 用固定的日均电价向量配合固定的日均负荷曲线，丢失了"高负荷 ↔ 高价"的正相关结构，而这一结构会显著抬高实际全年费用。

论文建议写法："附件1 为 2025 年典型日（365 天逐时段均值）曲线；问题1 给出的是该典型日的最优计划与费用，属于日均口径。由于负荷、光伏与电价的日间波动（CV 13.5%–20.8%）以及日负荷与日电价的正相关（r = 0.898），该费用不能直接外推为 334 天的平均最优费用；全年的最优费用由问题2/3/4 逐日求解后汇总给出。"

■ 5. 问题 2 模型（日重复电价 + 实际负荷/光伏 + 紧急购电）

▸▸ 5.1 与原问题的差异

  • 电价：仍取附件1（题面"每天的电价相同"）；
  • 负荷/光伏：改为附件2 的逐日实际值（365 天，每天不同）；
  • 新增：若微网提供电能低于小区负载，缺口需紧急购电，电价 = 交易时刻电价 × 5；
  • "除紧急购电费用外，其他时间段的购电费用均按计划购电量计算" → 计划购电的成本基数是 p^plan，与执行情况无关。

▸▸ 5.2 模型 (P2)（逐日独立）


│ 对每个 d ∈ 𝒟_year（365 天）：
│     min  Σ_t c_t·p_{d,t}  +  Σ_t 5·c_t·z_{d,t}
│     s.t. p_{d,t} + y_{d,t} − x_{d,t} − g_{d,t} − z_{d,t} = net_{d,t}·Δt
│          其中 net_{d,t} = load_{d,t} − pv_{d,t}（kW），乘 Δt = 1/6 后为 kWh
│          S_{d,t} = S_{d,t−1} + η·x_{d,t} − y_{d,t}/η,  S_{d,0} = S_{d,144} = 6000
│          1200 ≤ S_{d,t} ≤ 10800,  0 ≤ x_{d,t},y_{d,t} ≤ 833.3333
│          0 ≤ g_{d,t} ≤ pv_{d,t}·Δt                      （限光松弛，见 4.2.1）
│          0 ≤ z_{d,t} ≤ max(0, −net_{d,t}·Δt)            （紧急购电；上界为"局部确实缺电"的自然界）
│          p_{d,t} ≥ 0
│     报告：p_{d,t}、X_{d,b}、Y_{d,b}、z_{d,t}（只列 z > 0 的时段）

▸ 等价写法：把 z 移到等号左边（p + y − x − g − z = net·Δt）并给 z 加上界 max(0, −net_t·Δt)，
▸ 与"仅当净负荷为负（光伏余量）且无法由储能吸收时才缺电"完全一致。
▸ 
▸ ⚠ 首末 SOC 的实现要点（本次踩坑）：S_{d,t} 只由递推定义时，t = 0 的递推行含不存在的 S_{d,−1}，必须把该行右端取 6000（而不是 0），并另加一行 S_{d,0} = 6000；t = 144 的端值用 S_{d,143} = 6000 的变量界或单独等式锁定。否则模型会返回 S_0 = 6750 这类违反给定初值的"最优解"。

▸▸ 5.3 可行性与"紧急购电"的建模逻辑（论文手重点段落）

为什么 z 必须显式作为松弛变量：题目并未说"一定会短缺"，而是给出惩罚目录（5 倍电价）。把 z 写成非负松弛量后：
  • 若计划已能覆盖负载，最优解自动取 z_t = 0（因为 5c_t > c_t，能不用就不用）；
  • 若某些时段的负载超出"光伏 + 储能最大放电 + 计划购电"，则 z_t 被迫为正 —— 这就是紧急购电的触发口径。

命题 6（紧急购电触发条件，逐时段） 令 x̄ = ȳ = P_max·Δt = 833.3333 kWh（交流侧）。在时段 t 不缺电的充要条件是存在可行的 (x_t, y_t, g_t) 使

│ y_t − x_t + p_t − g_t ≥ net_t·Δt 且 p_t ≥ 0, g_t ≥ 0, 0 ≤ y_t ≤ ȳ, x_t ≥ 0

于是储能单时段最多顶 833.3333 kWh 的净负荷，其余必须由外网（计划购电或紧急购电）覆盖。

▸ 注意口径：833.3333 是交流侧放电量上限（题目给的 5000 kW 直接约束 y_t）。若按储能侧口径 y_t/η ≤ 833.3333 收紧，则该阈值降为 750 kWh，结论更强。本队采用交流侧口径（y_t ≤ 833.3333），并在敏感性分析中给出 750 情形。

▸▸ 5.4 结果文件与"计划购电/紧急购电"的关系（重要口径辨析）

本队的核心裁决是：p_{d,t}（计划购电量）是决策变量，取 p ≥ 0 无上界。由此：

+-----------------------------------+---------------------------------------------------------------------------+
| 情形                                | 结论                                                                        |
+-----------------------------------+---------------------------------------------------------------------------+
| 计划购电无上界（本队口径）                     | 最优解把 p 定得足够高，z_t 恒为 0（因为 5c_t > c_t）——这是"完全信息下计划总能兜住负载"的必然结果              |
| 计划购电存在逐时段外生上限 p^cap_t（本队提供的敏感性口径） | z_t 非零，且 z_t ≥ max(0, net_t + x_t − y_t + g_t − p^cap_t)；上限越紧，紧急购电越多，费用越高 |
+-----------------------------------+---------------------------------------------------------------------------+

为什么采用"无上界"主口径：
  1. 题目未给出任何购电容量/合约上限，凭空引入外生上限属于额外假设；
  2. 反而必须报告"紧急购电为什么是 0"这一结论——它说明在完全信息、无购电上限时，纯计划购电即可保证供电，紧急购电机制不会被触发；
  3. 表3 在论文中照实填报：给出 2025.3.20 / 6.21 / 9.23 / 12.21 四天的紧急购电量（本队口径下为 0 kWh），并同时给出敏感性口径（设定 p^cap_t 为当日峰值净负荷的 70%/85%/100%）下的紧急购电结果，说明"若常规购电通道受限则需要多少紧急电量"。

▸ ⚠ 待队长裁决的口径分歧：若竞赛出题意图是"计划购电量为事先承诺的固定量、缺口必须紧急购电"，则需把 p 改为外生常量或加上界。本队已把该情形参数化（pup/pcap 字段见 model_variables.json），切换成本极低。编程手请按主口径实现，同时保留 pcap 开关。

■ 6. 问题 3 模型（两阶段 / 滚动调整 + 违约与超购电价）

▸▸ 6.1 信息结构与决策时刻

+------------+-------------------------+--------------------------+
| 决策时刻       | 已有信息                    | 可决策范围                    |
+------------+-------------------------+--------------------------+
| 0:00（k=0）  | 附件3 0:00 预报（未来 24 小时整点） | 全天 144 时段 → p^plan       |
| 6:00（k=1）  | 附件3 6:00 预报（未来 24 小时）   | 6:00–24:00（时段 37..144）   |
| 12:00（k=2） | 附件3 12:00 预报（未来 24 小时）  | 12:00–24:00（时段 73..144）  |
| 18:00（k=3） | 附件3 18:00 预报（未来 24 小时）  | 18:00–24:00（时段 109..144） |
+------------+-------------------------+--------------------------+

非预期性（non-anticipativity）：时刻 k 的决策只能依赖该时刻及之前的信息。上述"决策范围限制"就是非预期性在本问题的确定性等价形式：6:00 不能改 0:00–6:00 已执行的动作。严格写法为

│ p^adj_{d,t} 在时刻 k 的取值  ⟂  {附件3 中发布时刻 > k 的预报}   ∀k
│ ⟺ p^adj 的第 t 个分量的信息集为 σ(附件3 发布时刻 ≤ ⌊6(t−1)/36⌋ 的行)

▸▸ 6.2 计价规则与目标函数

题目三段计价：
  1. 计划购电费用 = Σ_t c_t · p^plan_t；
  2. 紧急购电费用 = Σ_t 5c_t · z_t；
  3. 调整购电量相关费用：
  • 下调部分（调整 < 计划）：违约电价 = 交易时刻电价 × 50% → Σ_t 0.5 c_t · v_t
  • 上调部分（调整 > 计划）：超出部分电价 = 交易时刻电价 × 1.5 → Σ_t 1.5 c_t · u_t

总费用：

│ Total = Σ_t c_t·p^plan_t + Σ_t 5c_t·z_t + Σ_t (1.5 c_t·u_t + 0.5 c_t·v_t)
│       = Σ_t c_t·p^adj_t + Σ_t 0.5 c_t·v_t + Σ_t 5c_t·z_t          （因 p^adj = p^plan + u − v）

两种写法等价，第二种更适合直接对 p^adj 建模。

▸▸ 6.3 模型 (P3)（逐日，两阶段确定等价 LP）


│ 对每个 d ∈ 𝒟：
│     min  Σ_t c_t·p^adj_{d,t} + 0.5·Σ_t c_t·v_{d,t} + 5·Σ_t c_t·z_{d,t}
│ 
│     s.t. （第一阶段：0:00 计划）
│          p^plan_{d,t} + y^plan_{d,t} − x^plan_{d,t} − g^plan_{d,t} = net^{fore0}_{d,t}·Δt      ∀t
│          S^plan_t = S^plan_{t−1} + η x^plan_t − y^plan_t/η,  S^plan_0 = S^plan_144 = 6000
│          1200 ≤ S^plan_t ≤ 10800,  0 ≤ x^plan, y^plan ≤ 833.3333,  p^plan ≥ 0,  0 ≤ g^plan ≤ pv·Δt
│ 
│          （第二/三/四阶段：6/12/18 调整，仅调整未来时段）
│          p^adj_{d,t} + y^adj_{d,t} − x^adj_{d,t} − g^adj_{d,t} − z_{d,t} = net^{actual}_{d,t}·Δt  ∀t
│          S^adj_t = S^adj_{t−1} + η x^adj_t − y^adj_t/η,  S^adj_0 = S^adj_144 = 6000
│          1200 ≤ S^adj_t ≤ 10800,  0 ≤ x^adj, y^adj ≤ 833.3333,  p^adj ≥ 0, z ≥ 0, 0 ≤ g^adj ≤ pv·Δt
│ 
│          （偏差分解）
│          p^adj_{d,t} − p^plan_{d,t} = u_{d,t} − v_{d,t},  u ≥ 0, v ≥ 0
│          u_{d,t} > 0 只允许在 t ≥ 37 / 73 / 109（对应 6/12/18 之后）
│          v_{d,t} > 0 同理（下调也只能发生在信息更新之后）

其中 net^{fore0} 由附件3 0:00 预报换算，net^{actual} 由附件2 实际值换算（用于结算与最终结果）。

▸ 口径提示：若 0:00 计划用预报、调整用实际，则"调整"包含了全部预报误差的修正；这正是题目"根据附件2 中的小区负载和光伏发电及附件3 的光伏发电预报数据"的用法。

▸▸ 6.4 是否引入其他时刻预报？（题目明确要求分析）

判据（必须给出定量口径） 引入时刻 k 的调整，其价值定义为：


│ Gain(k) = C(base_k−1) − C(base_k)
│ 其中 C(base) = 在"只能用发布时刻 ≤ k 的预报做决策、但按实际 net 结算"下的最小总费用

命题 8（上界） 任何调整的收益上界为"用完全信息（实际负荷/光伏/电价）重优化 + 允许无成本调价"得到的最优费用与计划费用之差：

│ Gain_total ≤ C_plan_only − C_perfect_info

而每一次额外调整的净收益必须再减去违约/超购的附加成本。因此判据是


│ 值得引入时刻 k ⟺  E[预报误差带来的费用节省]  >  0.5·Σ E[c_t v_t] + 1.5·Σ E[c_t u_t] 的净增量 + 决策成本

结构性论证（可直接写进论文）：
  1. 物理必要性：夜间时段（0:00–6:00）的光伏为 0，负荷为日常低谷，储能放电行为受"不得低于负载"约束而极度受限，此时没有可套利空间；且该时段的预报误差本身为 0（见 3.5.1：0:00–4:00 的 MAE = 0.000，逐位精确命中 100%）。故不建议新增 0:00–4:00 之间的任何时刻（例如 3:00），因为它既无套利空间也无预测误差可修正。
  2. 数据给出了一条明确的正面答案：必须用好 6:00。附件3 的预报精度按发布时刻差异很大（全样本复核）：

+-------+----------+-----------------------+---------------+
| 发布时刻  | MAE (kW) | 覆盖的当日剩余时段             | 相对 0:00 的精度改善 |
+-------+----------+-----------------------+---------------+
| 6:00  | 97.484   | 6:00–24:00（剩余 18 小时）  | +46.2%（最准）    |
| 0:00  | 181.313  | 全天 144 时段             | 基准            |
| 12:00 | 207.866  | 12:00–24:00（剩余 12 小时） | −14.6%        |
| 18:00 | 259.893  | 18:00–24:00（剩余 6 小时）  | −43.3%（最差）    |
+-------+----------+-----------------------+---------------+

即：6:00 的预报比 0:00 准 46.2%，且覆盖当天剩余的全部 18 小时（占 3/4 天）。因此"是否值得引入其他时刻预报"在本数据下有一个明确的数据支持答案：6:00 的调整是收益最高的；12:00 次之（覆盖午间光伏回落与傍晚电价峰值）；18:00 收益最低（只覆盖 5 个整点、19:00–23:00 的误差又几乎为 0，且其自身 MAE 最差）。
  3. 误差的空间分布决定了收益位置：预报误差全部集中在 06:00–18:00，峰值在 11:00（MAE 769.4 kW）。因此 6:00 的更新主要修正 6:00–12:00（含 11:00 的误差峰），12:00 的更新主要修正 12:00–18:00，二者互补且都落在白天。
  4. 是否新增题面之外的时刻（3:00/9:00/15:00/21:00 等）：结论仍是不必新增，但理由与上一版不同——不是因为"没有收益"，而是因为题面给定的 0:00/6:00/12:00/18:00 已经恰好覆盖了误差峰值（11:00）前后与电价峰值（18:00–20:00）之前，新增时刻的边际信息增量有限，且每新增一次调整都要支付 0.5·c·v 或 1.5·c·u 的偏差成本。若做敏感性分析，建议只增补 9:00 与 15:00（分别位于 11:00 误差峰与 18:00 电价峰的前 2–3 小时，是理论上收益最高的两个候选点），报告 Gain 的百分比改善。
  5. 本轮修订说明：初版文档的结论是"无需额外引入"，理由是"0:00–6:00 无套利空间、12:00 收益最大"。编程手提供的分发布时刻 MAE 数据（6:00 最准、覆盖 76% 的剩余时间）表明 6:00 的调整价值被我低估了，故此处按数据修订：明确主张用好题面已给的 6:00 与 12:00 两次调整，并只在敏感性分析中增补 9:00/15:00。

▸▸ 7.1 与问题2/3 的差异

▸▸ 7.2 两种口径（必须显式声明，论文中二选一并给出理由）

+-----------------+-----------------------------------------------------------------------------+-----------------------------------------+
| 口径              | 数学形式                                                                        | 适用                                      |
+-----------------+-----------------------------------------------------------------------------+-----------------------------------------+
| D1 确定性等价（本队主口径） | 把 c_{d,t} 视为已知实现值，逐日求解 (P2)/(P3) 的变体                                        | result4-2 / result4-3 的填报（附件4 提供了全年实现值） |
| D2 滚动/在线决策      | 每日 0:00 只知道历史电价，用日间价格模型（如"前一日曲线 + 时段均值回归"）生成预测 ĉ_{d,t}，按 ĉ 求计划，执行后又可用实际值做调整 | 论文的"策略稳健性"章节，验证 D1 方案在"电价未知"下的可实现性      |
+-----------------+-----------------------------------------------------------------------------+-----------------------------------------+

问题4-2 模型：在 (P2) 中把 c_t → c_{d,t}，逐日求解（附件4 逐日不同价）：

│ min Σ_t c_{d,t}·p_{d,t} + Σ_t 5·c_{d,t}·z_{d,t}
│ s.t. 同 (P2)（含 1200 ≤ S ≤ 10800、0 ≤ x,y ≤ 833.3333、S_0 = S_144 = 6000）

问题4-3 模型：在 (P3) 中把 c_t → c_{d,t}（计划、调整、紧急三项都用当日对应时段的实际电价）：

│ min Σ_t c_{d,t}·p^adj_{d,t} + 0.5·Σ_t c_{d,t}·v_{d,t} + 5·Σ_t c_{d,t}·z_{d,t}

▸▸ 7.3 附件4 的两个必须处理的数据问题

  1. 极端低价：全样本 52,560 个电价中存在 9 个 < 0.05 元/kWh 的样本（最小 0.0076，2025-04-26 当日 max/min = 157）。这些点会让"充电成本 ≈ 0"从而触发近乎无限量的充电，但由于单时段充电量被 833.3333 kWh 限死，不会导致无界解，只会在该时段充满储能。处理选择见 9.5。
  2. 日价格比：全年日价格比中位数 4.33（远高于问题1/2 的 3.76）→ 波动电价下套利空间更大，储能利用率会显著高于问题1/2。

▸▸ 7.4 稳健性检验（论文加分项）

用 D2 口径做回测：对每个 d，仅用 d−1 及更早的电价构造预测，求解计划，再按实际 c_{d,t} 结算，报告

│ Regret = C_D2 / C_D1 − 1

若 Regret 很小（预期 < 5%），说明"以日为周期的确定等价计划"在实时电价下仍可用。

▸▸ 9.3 "其他时间段的购电费用均按计划购电量计算" —— 采用 p 只有下界、无上界（口径 C1）

若把该句理解为"p 被强制等于某个事先固定的 p^plan"，则问题2 的最优解必然让 p^plan 覆盖全部净负荷，紧急购电为 0（因为 5c_t > c_t）；若把 p 的外生上限设得太紧，则可能需要巨额紧急购电。关键推论：在完全信息下，"计划购电"总能被定得足够高，因此紧急购电量的取值完全由"常规购电通道是否有容量上限"决定，而题目并未给出该上限。

本队的裁决与呈现方式：

+--------------+-----------------------------------------------------------+-------------------------------------------+
| 口径           | 设置                                                        | 结果特征                                      |
+--------------+-----------------------------------------------------------+-------------------------------------------+
| C1（主口径，本队采用） | p_{d,t} ≥ 0 无上界；z_t ∈ [0, max(0, −net_t)]                 | z_t ≡ 0——完全信息下纯计划购电即可保证供电；论文照实报 0，并解释原因   |
| C2（敏感性口径）    | p_{d,t} ≤ p^cap_t，p^cap_t = α × 当日峰值净负荷（α = 0.7/0.85/1.0） | 上限越紧，z_t 越大、费用越高；用于回答"若常规购电受通道限制需要多少紧急电量" |
+--------------+-----------------------------------------------------------+-------------------------------------------+

理由：
  1. 题目没有给任何购电容量/合约上限，凭空引入外生上限是额外假设，违反"不引入题目未给参数"的建模纪律；
  2. C1 下 z ≡ 0 本身是有信息量的结论（说明供电可靠性由计划购电兜底，而非紧急机制）；
  3. C2 只需在上界数组上加一个字段（p_cap_t），切换成本极低，已写入 model_variables.json 的 parameters。

▸ ⚠ 这是一个需要队长在论文定稿前明确声明的口径。 若最终选择"紧急购电必须非零"的叙事，请把 p^cap_t 作为外生参数引入（并在论文中说明其来源与取值依据）；否则不要人为压低 p 的取值。

▸▸ 9.4 问题2 的紧急购电是否允许"时间平移"到便宜时段 —— 不允许

题面"如果低于负载，需向外网紧急购电，其电价是交易时刻电价的 5 倍"中的"交易时刻"= 缺口发生的时段。故 z_t 是该时段就地补足的量，不可用其它时段的便宜电替代（否则会与"紧急"语义矛盾）。

▸▸ 9.7 问题3 的"是否引入其他时刻预报" —— 用好题面已给的 6:00 与 12:00；不新增题面外时刻（队长 A19 裁定）

▸▸ 9.8 光伏限光（弃光）松弛 —— 必须引入 g_t

这是本次分析中最重要的一条建模发现。

本节已按队长 A8 裁定勘误（见 4.2.1 的完整说明），要点：

题面"微网提供的电能不可低于小区负载"是不等式（等价 p_t ≥ 0）；配合"不允许上网"，光伏余量在原理上可能无法被储能全部吸收。为避免把平衡写成等式后出现"强制储能吸收全部余量"的刚性不可行（队长首版 LP 即因此不可行），模型中必须留出可行域松弛。

实测数据（建模手复核，单位为 kWh/时段，已乘 Δt = 1/6）：

+---------------------+----------------------------------+--------------+------------------+
| 数据                  | 单时段最大光伏余量                        | 吸收上限 x̄      | 越限时段数            |
+---------------------+----------------------------------+--------------+------------------+
| 附件1（典型日均，144 时段）    | 352.9209 kWh（= 2117.53 kW × 1/6） | 833.3333 kWh | 0 / 144          |
| 附件2（365 天 × 144 时段） | 单日最大需吸收约 2004 kWh 级              | 833.3333 kWh | 34 / 365 天存在越限时段 |
+---------------------+----------------------------------+--------------+------------------+

处理选择：引入限光量 g_t ∈ [0, pv_t·Δt]，能量平衡写为

│ p_t + y_t − x_t − g_t = net_t·Δt      （即 p_t = net_t·Δt + g_t + x_t − y_t ≥ 0）

  • 附件1 的最优解中 Σg_t = 0——30 个余量时段合计 6,247.96 kWh 全部可入储能；因此论文中不要写"必须限光否则不可行"（该说法已被实测证伪）；
  • 问题2 全年限光 990,168.09 kWh，占全年光伏余量 3,120,221.00 kWh 的 31.7%；365 天中 268 天限光为 0、其余 97 天为正；所以 g_t 在问题2/3/4 中是实质性变量；
  • 等价写法：把平衡写成不等式 p_t + y_t − x_t ≥ net_t·Δt 即可，无需显式 g_t（两者最优值相同）。本队主口径保留显式 g_t，便于报告 Σg_t。
  • 物理解释：光伏逆变器限功率运行（curtailment），多余电量不被利用、也不上网；g_t 无成本，其"代价"体现为白丢的免费电量。

备选口径 H2'（若队长倾向"允许上网"）：把 g_t 换成上网电量，目标函数加入上网收益 −c_sell·g_t（c_sell 未给出，需自设，例如按 0.3 × c_t 或按 0）。该口径同样可行，但引入了题目未给的 c_sell。建议论文以主口径（限光）为主、H2'（上网）为对照。

▸ 建议编程手：把 g_t 作为常规变量实现（上界 pv_t·Δt），并在结果中单独报告 Σg_t（全天限光量）作为"供能充分性"的指标。附件1 应为 0；问题2 全年约 99.0 万 kWh，集中在 34 个高余量日。
