# 问题2费用目标可达性分析

对预测版问题2的统一保守系数 α 在 0.80–0.85 以0.005步长精细搜索，最优点为 α=0.825：

- 正常计划购电量：23,112,518.992795 kWh；
- 紧急购电量：366,602.001211 kWh；
- 正常计划购电费：14,223,990.033944 元；
- 紧急购电费：1,526,437.493849 元；
- 总费用：15,750,427.527793 元。

该结果仍高于1400万元目标约175.04万元。进一步放松为全年连续SOC优化只能节省约1.47万元，无法弥补差距。

原因是问题2必须在0:00仅凭预报固定购电计划，实际光伏未知；为避免5倍紧急电价，模型需要提前增加正常购电。若把附件2实际光伏用于计划、允许6/12/18时刻无代价调整，确实可能接近或低于1400万元，但那已经改变问题2的信息结构，分别属于完全信息基线或问题3滚动模型，不能作为问题2预测结果。

因此不建议强行更换模型追求1400万元：在题意约束下，15.75百万元是当前经测试的费用最优方案；1400万元只能通过改变“实际光伏未知”“调整有费用”“紧急电价5倍”等题目条件实现，缺乏严谨性。
