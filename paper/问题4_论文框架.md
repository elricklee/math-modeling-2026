# 问题4 论文框架：波动电价下重算问题2/3

## 1. 问题重述与新增裁定（0.5 页）

- 电价实时波动（附件4），重算问题2 与问题3。
- **两条新口径裁定（必须写）**：
  1. 价格信息因果——任意决策时刻只知当前之前的实际价格，未来靠预测（与负载完全同构）；
  2. 结算价 = 交易时刻实际电价——计划、调整、紧急（5 倍）均按成交当时实际价结算；价格预测误差直接进账单，预测的作用是决定"何时买"。
- 承接：4-2 光伏与问题2 同源（自建 SARIMA，不用附件3）；4-3 负载严格预测口径。

## 2. 数学模型：波动电价下的随机规划（目标方程与完整约束）

### 2.1 价格预测与联合情景（本问新增的两块原料）

- **价格因果预测器**：ĉ_t = 近 28 天**同星期几**逐时段中位数（与负载预测同构；MAE 0.0498 元/kWh，约均价 6.6%）。价格误差史 e^c_d = c_d − ĉ_d（严格过去）。
- **联合情景**：（e^l, e^v, e^c）**同一历史日 d 整体重采样** K = 200：
  $$c_{k,t}=\max\big(\hat c_t+e^c_{k,t},\ 0\big),\qquad \bar c_t=\tfrac1K\textstyle\sum_k c_{k,t}$$
  整日联合采样保留"高负载日恰是高价日"（日总量 vs 日均价 r=+0.898；误差日幅度相关 0.562）——独立抽签会破坏该结构导致错对冲。

### 2.2 4-2 目标方程（单阶段 + 分情景价格）

$$\min\ Z=\sum_{t=1}^{144}\bar c_t\,p_t\;+\;\frac{5}{K}\sum_{k=1}^{K}\sum_{t=1}^{144}c_{k,t}\,z_{k,t}$$

约束与问题2 完全相同（逐情景平衡、SOC、功率口、z/g/w 追索）。关键区别：第一阶段量 p 按情景均价 c̄ 计期望成本（它按实际价结算、实际价未知），紧急 z_k 按各情景价 c_{k,t} 计价（高价情景的缺口更痛 → 对冲余量自动加大，控制实验 95.4 vs 固定价 84.8 GWh）。

### 2.3 4-3 目标方程（多阶段 + 分情景价格）

r ∈ {0,6,12,18} 对剩余时段 T_r 重解：

$$\min\ Z_r=\begin{cases}\sum_{t\in T_0}\bar c^r_t q_t+\frac{5}{K}\sum_k\sum_{t\in T_0}c^r_{k,t}z_{k,t}, & r=0\\[4pt]\sum_{t\in T_r}\big[1.5\,\bar c^r_t u_t+0.5\,\bar c^r_t v_t\big]+\frac{5}{K}\sum_k\sum_{t\in T_r}c^r_{k,t}z_{k,t}, & r\in\{6,12,18\}\end{cases}$$

衔接约束 q_t − u_t + v_t = p^plan_t 与问题3 相同；光伏中心 = r 时刻附件3 发布预报（4-3 专属），负载中心 = SARIMA（严格口径）。

### 2.4 日内价格条件化与结算

- **条件化**：r 阶段剩余时段价格中心做水平修正 ĉ^r|_{T_r} = ĉ + mean(实际已过时段 − 预测已过时段)，再叠加联合误差情景。
- **结算（裁定）**：计划、调整、紧急全部按**交易时刻实际电价**（附件4）结算，紧急 5 倍实际价——LP 用期望价优化、账单按实际价开，价格预测误差直接进账单；预测的全部作用是决定"何时买"。

### 2.5 分步策略与建模思想

| 步骤 | 做什么 | 为什么 |
|---|---|---|
| ① 价格预测 | 28 天同星期几中位数曲线 | 稳健、无拟合风险；与负载预测器同构便于论文统一叙述 |
| ② 联合造情景 | 三种误差同日整体重采样 | 保留负载—价格强相关，是本问最重要的建模决定 |
| ③ 分情景定价 | 第一阶段量用 c̄、追索用 c_k | 与"按实际价结算"的裁定在期望意义下严格对齐 |
| ④ 优化与执行 | 与问题2/3 相同的 LP 与轨迹保护自适应储能 | 决策与执行层完全复用，只换信息结构 |
| 建模思想 | 电价成为第三个不确定源后，问题从"猜需求"升级为"猜需求×价格"的联合对冲 | 高负载×高价联合尾部才是真风险，均值分开工处理会系统性低估 |

## 4. 对比分析（1 页）

- 波动溢价：同管线下 Q2 固定→波动 +5.9%、Q3 +5.8%——电价不确定性本身的定价，构成"价格预测值多少钱"的量化答案。
- 4-3 < 4-2（Δ 10.2 万）：附件3 预报 + 调整权在波动电价下依旧增值；紧急购电 197k < 267k。
