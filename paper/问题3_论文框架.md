# 问题3 论文框架：多时刻预报下的计划—调整两阶段（严格口径）

> 对应结果文件 `results/CUMCM2026_C/result3.xlsx`｜核心结论一句话：**严格口径（负载与问题2 同源预测）下全年 14,620,483 元，低于问题2 的 14,697,898 元——附件3 预报与调整权的价值覆盖调整罚价；"是否需要更多预报时刻"的结论：用好题面已给的 0/6/12/18 即可**

## 1. 问题重述与裁定（0.5 页）

- 0:00/6:00/12:00/18:00 发布未来 24 小时整点光伏预报；0:00 定计划，其他时刻可调整；下调部分违约电价 50%、上调部分 150%、紧急 5 倍。
- **口径裁定（必须写明）**：**严格口径**——当天负载 0:00 不可知，与问题2 同源 SARIMA 预测（题面未提供负载预报源）；"附件2 当天负载视为已知"的读法已评估并**弃用**。附件2 的角色是执行结算的实际值。
- 调整覆盖当日至 24:00；日终 SOC 计划目标 6000。

## 2. 数学模型：多阶段随机规划（目标方程与完整约束）

记发布时刻集合 R = {0, 6, 12, 18}（小时），r 时刻覆盖的剩余时段 T_r = [6r, min(6r+36, 144))。

### 2.1 0:00 阶段（与问题2 同构，光伏中心换预报）

$$\min\ Z_0=\sum_{t=1}^{144}c_t\,q_t+\frac{5}{K}\sum_{k=1}^{K}\sum_{t=1}^{144}c_t\,z_{k,t}$$

光伏情景中心 = 附件3 0:00 发布预报（整点值按"小时保持"展开到 10 分钟，论文需声明该口径）；离散度取 **0:00 发布口径**的预报误差史（实际 − 该时刻预报，整日重采样、严格过去）。负载情景与问题2 完全同源（SARIMA 误差史）。

### 2.2 r ∈ {6, 12, 18} 阶段（对剩余时段 T_r 重解）

$$\min\ Z_r=\sum_{t\in T_r}\big[1.5\,c_t\,u_t+0.5\,c_t\,v_t\big]+\frac{5}{K}\sum_{k=1}^{K}\sum_{t\in T_r}c_t\,z_{k,t}$$

$$\text{(1) 与 0:00 计划的衔接：}\quad q_t-u_t+v_t=p^{\text{plan}}_t,\qquad t\in T_r$$
$$\text{(2) 逐情景平衡：}\quad q_t+y_t-x_t+z_{k,t}-g_{k,t}-w_{k,t}=\text{net}^r_{k,t}$$
$$\text{(3) SOC：从当前实际电量出发，日终 } S_{144}=6000;\quad 1200\le S_t\le 10800;\quad 0\le x_t+y_t\le 833.33$$

要点：① 0:00 计划费已沉没，r 阶段目标只含增量（罚价 + 期望紧急）；② 光伏中心换 r 时刻发布的预报（其覆盖未来 24 小时，仅取当日剩余部分），误差史用**同一发布时刻**的口径；③ "预付不退"读法下 v_t 恒为 0（下调严格劣势），实测全年零下调；④ 负载情景沿用 0:00 水平的误差曲线切片——保守简化（不用上午已实现信息更新负载预测），论文声明。

### 2.3 执行与结算

执行层沿用轨迹保护自适应储能（保护轨迹随最新发布更新）；结算 = 计划费（预付）+ 1.5×上调 + 0.5×下调 + 5×紧急。

### 2.4 分步策略与建模思想

| 步骤 | 做什么 | 为什么 |
|---|---|---|
| ① 0:00 计划 | 解 Z_0 得全天计划 p^plan | 与问题2 相同的期望费用最小化，只是光伏中心来自官方预报 |
| ② 逐发布重解 | 6/12/18 点以新预报为中心、带罚价重解剩余时段 | 调整罚价进目标 = 调整决策本身最优，而非"先按普通价求解、事后补罚金"的近似 |
| ③ 情景原料分口径 | 每个 r 维护各自的预报误差史 | 各发布时刻精度差异大（白天 MAE：6 点 97 / 0 点 181 / 18 点 260 kW），离散度不能共用一本账 |
| ④ 执行 | 储能实时补位（高于最新计划轨迹的盈余） | 与前问一致的执行裁定 |
| 建模思想 | 把"何时值得调整"交给优化器：只有当新预报引起的期望紧急变化 > 罚价时才产生非零 u | 信息价值内生定价，替代任何手工调整规则 |

## 3. 结果（1 页）

- 全年总费用 **14,620,483 元**（验证期 4,282,790、盲评测试期 4,318,403）。
- 计划购电 22,420,750.54 kWh（计划费 13,763,558.35 元）→ 调整后执行 22,569,267.72 kWh（净上调 148,517 kWh）；紧急购电 208,021.96 kWh（330 天）。
- 表1/表3 指定日期（计划购电 kWh / 计划费 元）：3.20 = 73,051.25 / 44,642.18；6.21 = 37,699.77 / 22,024.86；9.23 = 76,966.69 / 48,227.68；12.21 = 99,856.21 / 64,503.74；表2 自 result3.xlsx 充放电量工作表。
- **零下调的解释（论文必写）**：预付不退 + 下调另付 0.5 倍违约金的读法下，取消已付款电量严格劣势，故全年调整只向上。若采用"计划高出部分按 0.5 倍结算"的替代读法，下调才有意义——口径声明必须二选一并说明。

## 5. "是否需要引入其他预报时刻"（0.5–1 页）

- 现有依据（预报精度口径）：6:00 发布最准（白天 MAE 97.5 kW）、0:00 约 181、18:00 最差（260）但仅覆盖当日 5 小时；结论：**用好 0/6/12/18，不建议新增题面外时刻**。
